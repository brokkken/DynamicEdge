# Dynamic Edge для Windows 11

**Dynamic Island для Windows.** Компактная капсула в верхней части экрана, которая оживает, когда в системе что-то
происходит: играет музыка, пришло уведомление, подключили зарядку, изменилась громкость. Выглядит как «динамический
остров» на iPhone, но работает на Windows 10/11 и настраивается под себя: цвета, форма, анимации, содержимое.

Приложение написано на C# / WPF (.NET 10), без сторонних NuGet-пакетов, и использует реальные API Windows.

## Возможности

| Функция | Что показывает |
|---|---|
| Музыка | Название трека, исполнитель, обложка, прогресс, кнопки Play/Pause, вперёд и назад, анимированный эквалайзер в цвет обложки. Работает со всеми плеерами, публикующими системную медиасессию (Spotify, Яндекс Музыка, браузеры, Медиаплеер и др.) |
| Уведомления | Значок приложения-отправителя, заголовок и текст уведомления Windows |
| Батарея | Процент заряда, анимация зарядки, предупреждение о низком заряде |
| Громкость | Анимированный индикатор в реальном времени, состояние «без звука» |
| Микрофон | Оранжевая точка, когда микрофон используется, с названием приложения; уведомление о включении и выключении микрофона |
| Буфер обмена | Тост при копировании, последние 3 записи в развёрнутой панели (клик по записи копирует её обратно) |
| Таймер и секундомер | Обратный отсчёт и секундомер прямо в капсуле, звук и анимация по завершении, свои пресеты |
| Мониторинг | CPU, RAM, видеокарта (GPU), диск, скорость сети (отправка и приём) и температура, если Windows её отдаёт. Мини-индикаторы можно вывести прямо в свёрнутую капсулу |
| Тексты песен | Текущая строка текста с подсветкой в такт музыке (сервис LRCLIB) |
| Итоги и история | Сколько музыки вы послушали за неделю, любимые исполнители и треки (только на вашем ПК) |
| Полка | Быстрые ссылки: перетащите ссылку из браузера на капсулу или вставьте из буфера |
| Погода | Температура и состояние погоды для вашего города (Open-Meteo) |
| Глазки | Живое «лицо» в свёрнутой капсуле: моргают, следят за курсором, радуются, засыпают, пульсируют в такт музыке и реагируют на события |

Дополнительно: тёмная, светлая и системная тема; настройка формы, анимаций, размера, прозрачности и положения;
порядок блоков и содержимое капсулы; выбор монитора; автозапуск; иконка в трее; глобальные горячие клавиши;
автоматическое скрытие в полноэкранных играх и презентациях.

## Установка

Требования: Windows 10 (сборка 19041) или Windows 11, 64-разрядная версия.

### Быстрая установка: `DynamicEdge-Setup.exe`

1. Откройте раздел **Releases** и скачайте `DynamicEdge-Setup.exe` из последнего релиза.
2. Дважды щёлкните по файлу. Если Windows покажет окно «Windows защитила ваш компьютер» (SmartScreen), нажмите
   **Подробнее → Выполнить в любом случае**. Установщик не подписан платным сертификатом, поэтому Windows не знает
   издателя.
3. Согласитесь на запрос прав администратора и нажмите **Далее → Установить**. Установщик добавит сертификат
   издателя в доверенные (Windows требует этого для установки пакета) и установит приложение.
4. На последней странице оставьте галочку **Запустить Dynamic Edge** и нажмите **Завершить**.
5. При первом запуске откроется окно приветствия: выберите, нужен ли автозапуск, и нажмите **Начать**. Сверху по центру
   экрана появится капсула, а у часов в трее — значок приложения.

Установка выполняется для текущего пользователя Windows. Подтверждайте запрос прав той же учётной записью, под
которой будете пользоваться приложением. Файл `DynamicEdge-Setup.exe` можно просто переслать другу: ему не нужен GitHub.

### Ручная установка из MSIX (альтернатива)

Внутри установщика находится подписанный MSIX-пакет. Его можно установить и вручную.

1. Скачайте из **Releases** три файла: `DynamicEdge.msix`, `DynamicEdge.cer`, `install.ps1`. Положите их в одну папку
   (архив должен быть распакован).
2. Нажмите правой кнопкой на `install.ps1` → **Выполнить с помощью PowerShell** и согласитесь на права администратора.
   Если выполнение скриптов запрещено, откройте PowerShell от администратора и выполните команду с полным путём к файлу:

   ```powershell
   powershell -ExecutionPolicy Bypass -File "C:\путь\к\папке\install.ps1"
   ```

   Путь указывайте полностью: запись вида `Папка\install.ps1` не сработает, PowerShell ищет файл относительно текущей папки.

### Разрешите доступ к уведомлениям (по желанию)

Чтобы капсула показывала уведомления Windows, откройте **Параметры → Конфиденциальность и защита → Доступ к
уведомлениям** и разрешите доступ приложению. Статус функции виден в настройках: **Функции → Уведомления Windows**.

## Обновление

1. Закройте приложение: правый клик по значку в трее → **Выход**.
2. Скачайте `DynamicEdge-Setup.exe` из нового релиза и запустите его.
3. Новая версия установится поверх старой. Настройки сохранятся.

## Использование

### Капсула

| Действие | Результат |
|---|---|
| Ничего не происходит | Маленькая капсула. Если играет музыка, видны обложка и эквалайзер; если идёт таймер, видно оставшееся время; если используется микрофон, горит оранжевая точка |
| Навести курсор | Капсула слегка расширяется и показывает трек, время таймера, заряд батареи и часы |
| Клик по капсуле | Раскрывается полная панель |
| Повторный клик | Панель сворачивается |
| Курсор ушёл с панели | Через 5 секунд панель сворачивается сама |
| Событие системы (громкость, зарядка, уведомление, копирование…) | Капсула на несколько секунд показывает тост и возвращается в прежнее состояние. Пока курсор над тостом, он не исчезает |

Капсула не забирает фокус у других окон, не отображается в панели задач и Alt+Tab, а прозрачные области пропускают клики.

### Развёрнутая панель

- **Музыка:** обложка, название, исполнитель, прогресс, кнопки управления плеером и текст песни. Кнопка «…» открывает
  сведения о треке (альбом, длительность, источник), копирование названия и карточку «Поделиться» (картинка с обложкой
  уходит в буфер обмена). Жесты: двойной клик по обложке ставит паузу, свайп по обложке влево или вправо переключает
  трек, колёсико мыши над капсулой меняет громкость.
- **Вкладки:** **Главная**, **Итоги** (статистика прослушивания) и **Полка** (ссылки). Кнопка-«булавка» справа
  закрепляет или открепляет капсулу.
- **Мониторинг:** карточки CPU, RAM, GPU, диск, отправка и приём по сети, температура. Карточки, для которых Windows не
  даёт данных (например, температура), скрываются.
- **Погода:** температура, ощущаемая температура и состояние (если включена в настройках).
- **Таймер:** кнопки пресетов запускают обратный отсчёт (по умолчанию 1, 5, 10 и 25 минут), кнопка с часами запускает
  секундомер, кнопка с квадратом сбрасывает. Когда таймер закончится, капсула подаст сигнал и «встряхнётся».
- **Буфер обмена:** последние 3 скопированных текста. Клик по записи копирует её обратно в буфер. Содержимое,
  помеченное менеджерами паролей как скрытое, не показывается.

Блоки, отключённые в настройках, в панели не отображаются.

### Значок в трее

| Действие | Результат |
|---|---|
| Левый клик | Развернуть или свернуть капсулу |
| Двойной клик | Открыть настройки |
| Правый клик | Меню: развернуть, показать или скрыть капсулу, настройки, выход |

Чтобы полностью закрыть приложение, выберите в меню трея **Выход**.

## Настройки

Откройте настройки двойным кликом по значку в трее или через его меню. Изменения применяются сразу и сохраняются
автоматически.

| Вкладка | Что настраивается |
|---|---|
| Общие | Автозапуск; поведение в играх (скрывать, показывать мониторинг, ничего не менять); закрепление и сброс положения; автоскрытие, когда нечего показывать; монитор, отступ сверху и смещение по горизонтали; время показа уведомлений; порог низкого заряда; длительность таймера по горячей клавише |
| Функции | Включение и выключение каждого блока: музыка, уведомления, батарея, громкость, микрофон, буфер обмена, таймер, системная информация |
| Внешний вид | Шрифт (любой установленный), тема (тёмная, светлая, как в Windows), размер капсулы (80–130 %), прозрачность фона |
| Форма и анимации | Скругление, обводка, тень, размеры, характер и скорость анимаций (см. ниже) |
| Содержимое | Что показывать в свёрнутой капсуле (в том числе погоду, раскладку клавиатуры и мониторинг), порядок блоков панели, пресеты таймера (см. ниже) |
| Глазки | Включение, слежение за курсором, танец под музыку, засыпание, размер, цвет, проверка настроений (см. «Глазки») |
| Сервисы | Погода (город), тексты песен, история прослушивания и её удаление |
| Горячие клавиши | Три глобальных сочетания: нажмите на поле и введите комбинацию (нужен Ctrl, Alt, Shift или Win) |
| О программе | Версия, тип установки, пути к файлам настроек и лога, кнопка открытия папки с данными |

## Кастомизация

Оформление и поведение капсулы можно подстроить под себя. Всё применяется сразу. Кнопка
**«Показать в развёрнутом виде (предпросмотр)»** на вкладке «Форма и анимации» разворачивает капсулу и удерживает её
открытой, пока вы подбираете параметры. Клик по капсуле снимает удержание.

### Форма и анимации

| Параметр | Что меняет | Диапазон |
|---|---|---|
| Скругление углов | Максимальный радиус: от «таблетки» до почти прямоугольника | 4–40 px |
| Толщина обводки | Тонкая рамка по краю капсулы (0 — без рамки) | 0–3 |
| Сила тени | Глубина тени под капсулой (0 — без тени) | 0–80 % |
| Высота в покое | Размер свёрнутой капсулы | 26–50 px |
| Ширина панели | Ширина развёрнутой панели | 380–560 px |
| Характер раскрытия | **Упругая** (с пружинным «перелётом»), **Мягкая** (плавная, без перелёта), **Мгновенная** (размер меняется сразу) | — |
| Сила пружины | Насколько заметен перелёт при упругом раскрытии | 0,1–0,8 |
| Скорость анимаций | Ускоряет или замедляет все переходы | 0,5×–2× |

Общий переключатель «Включить анимации» отключает все анимации сразу. Кнопка сброса возвращает значения по умолчанию.

### Содержимое и раскладка

- **Свёрнутая капсула.** Включайте и отключайте: обложку трека, эквалайзер, название трека и исполнителя, таймер,
  заряд батареи, часы. Если не включено ничего и в системе ничего не происходит, капсула остаётся пустой (или
  скрывается при включённом автоскрытии).
- **Порядок блоков.** Музыку, систему, таймер и буфер обмена в развёрнутой панели можно расставить в любом порядке
  кнопками «Выше» и «Ниже».
- **Пресеты таймера.** Вместо 1/5/10/25 минут укажите свои значения через запятую (до 5, например `3, 15, 45, 90`).
  Значения от 60 минут, кратные часу, подписываются как «1ч», «2ч». Значение применяется, когда вы уберёте курсор из поля.
- **Сброс.** На обеих вкладках есть кнопка возврата к значениям по умолчанию.

## Мониторинг, тексты песен, итоги и полка

**Мониторинг.** Развёрнутая панель показывает CPU, RAM, GPU, диск и скорость сети. Если включить на вкладке «Содержимое»
пункт «Мониторинг…», те же показатели с мини-индикаторами видны прямо в свёрнутой капсуле. Данные берутся из счётчиков
производительности Windows (те же, что в диспетчере задач).

**Режим игр.** На вкладке «Общие» выберите, что делать в полноэкранных играх: скрывать капсулу, показывать только
мониторинг (CPU, RAM, GPU, диск) или ничего не менять. Работает поверх игр в оконном и безрамочном режимах. Поверх
«чистого» полноэкранного режима Windows не даёт рисовать, а FPS приложение не измеряет.

**Тексты песен.** Текущая строка текста показывается в развёрнутой панели и меняется в такт музыке. Тексты берутся из
открытого сервиса [LRCLIB](https://lrclib.net): в него уходят только исполнитель, название и длительность трека.
Отключается на вкладке «Сервисы». Подсветка идёт по строкам, а не по словам: сервис отдаёт тексты построчно.

**Итоги недели.** Вкладка **Итоги** в панели: сколько музыки вы слушали, график по дням, любимые исполнители и треки.
История хранится только на вашем компьютере (`history.json` рядом с настройками). Её можно отключить и удалить на
вкладке «Сервисы».

**Полка.** Вкладка **Полка**: перетащите ссылку из браузера на капсулу (она сама развернётся) или нажмите «+ Из буфера».
Клик по плитке открывает ссылку, правый клик удаляет. Значок сайта загружается напрямую с самого сайта.

**Погода и раскладка.** Включите погоду на вкладке «Сервисы» и укажите город: температура появится в панели, а на
вкладке «Содержимое» можно вывести её в свёрнутую капсулу. Раскладка клавиатуры (RU, EN…) тоже может показываться в
свёрнутой капсуле.

**Перемещение.** Нажмите «булавку» в панели (или снимите галочку «Закрепить» в настройках) и перетаскивайте капсулу в
любое место экрана, в том числе на другой монитор. Положение запоминается; «Сбросить положение» возвращает её наверх.

## Глазки

В свёрнутой капсуле живут два глаза: они моргают, смотрят по сторонам и меняют выражение в зависимости от того, что
происходит. Включаются и настраиваются на вкладке **Глазки**.

| Ситуация | Что делают глазки |
|---|---|
| Вы работаете за компьютером | Спокойно смотрят, моргают (иногда дважды) |
| Курсор мыши где угодно на экране | Следят за ним (можно отключить, тогда смотрят по сторонам сами) |
| Навели курсор на капсулу | Радуются (глаза-«дужки») |
| Играет музыка | Пульсируют и подпрыгивают в такт **реальной громкости** звука на устройстве вывода |
| Сменился трек | Радуются и подпрыгивают |
| Пришло уведомление | Удивляются (если у уведомления нет собственной иконки, настроение видно прямо в нём) |
| Подключили зарядку или батарея полная | Радуются |
| Низкий заряд батареи | Уставшие и красные, пока не подключите зарядку |
| Используется микрофон | Настороженные и оранжевые, пока микрофон занят |
| Звук выключен или микрофон выключен | Закрывают глаза |
| Громкость выше 80 % | Удивляются |
| Запустили таймер | Прищуриваются и сосредоточиваются |
| Таймер завершился | Восторженно прыгают |
| Нет ввода с клавиатуры и мыши заданное время | Засыпают (глаза закрыты, над ними всплывают «z»), просыпаются при любом движении |

Что настраивается: включение, слежение за курсором, танец под музыку (глазки тогда заменяют эквалайзер), настроение в
уведомлениях, время до сна (0 — не засыпать), размер (0,6×–1,6×) и цвет (белый, цвет обложки трека, голубой, зелёный,
розовый, оранжевый). Кнопки «Проверить настроения» на вкладке показывают каждую реакцию сразу, не дожидаясь события.
В светлой теме белые глазки автоматически становятся тёмными.

## Горячие клавиши

| Сочетание по умолчанию | Действие |
|---|---|
| `Ctrl` + `Alt` + `D` | Развернуть или свернуть капсулу |
| `Ctrl` + `Alt` + `H` | Показать или скрыть капсулу |
| `Ctrl` + `Alt` + `T` | Запустить или остановить таймер (длительность задаётся в настройках, по умолчанию 5 минут) |

Если сочетание занято другим приложением, оно не сработает. Назначьте другое в настройках: информация о неудачной
регистрации пишется в лог.

## Ограничения Windows

| Функция | Как реализовано | Особенности |
|---|---|---|
| Музыка | Системные медиасессии (SMTC) | Работает только с плеерами, которые публикуют сессию |
| Уведомления | `UserNotificationListener` | Только в MSIX-версии (установка через `DynamicEdge-Setup.exe` подходит); нужно разрешение в параметрах Windows |
| Громкость и mute микрофона | Core Audio (`IAudioEndpointVolume`) | Стандартный индикатор громкости Windows остаётся на экране |
| Использование микрофона | Данные Windows о доступе к микрофону | Тот же источник, что у индикатора микрофона в трее |
| GPU, диск, сеть | Счётчики производительности Windows (PDH) | Загрузка GPU считается по счётчику «GPU Engine» (Windows 10 1709 и новее); если счётчика нет, карточка скрывается |
| Тексты песен | Сервис LRCLIB (lrclib.net) | Нужен интернет; подсветка по строкам; текст есть не у всех треков |
| Погода | Сервис Open-Meteo (open-meteo.com) | Нужен интернет; отправляется название города |
| Телефон (звонки, ответы на сообщения) | Не поддерживается | У Windows нет открытого API для «Связи с телефоном». Уведомления с телефона, которые Windows показывает у себя, капсула отображает как обычные |
| Температура | Счётчик «Thermal Zone Information» | Доступна не на всех компьютерах (зависит от BIOS и ACPI); если Windows не отдаёт данные, столбец скрывается. Точные датчики процессора требуют драйвера и прав администратора, поэтому не используются |
| Размытие фона (acrylic) | Не используется | Нестабильно на прозрачных WPF-окнах. Глубину создают полупрозрачность, обводка и тень |

## Если что-то не работает

**Установка не проходит**
- Запускайте установщик от имени администратора той же учётной записью, под которой работаете.
- Если вы ставите вручную из MSIX: файлы `.msix`, `.cer` и `install.ps1` должны быть распакованы и лежать в одной папке.
- Если PowerShell пишет, что файл не существует, укажите путь полностью (см. «Ручная установка»).

**Капсулы не видно**
- Нажмите `Ctrl+Alt+H`: возможно, она скрыта.
- Если на экране полноэкранное приложение или игра, капсула скрыта намеренно (отключается в настройках).
- Проверьте в настройках выбранный монитор и отступ сверху.
- Проверьте, что в трее есть значок приложения. Если нет, запустите приложение из меню «Пуск».

**Не показывается музыка** — включите воспроизведение в плеере. Если плеер не публикует системную медиасессию, отображение
невозможно (проверка: при воспроизведении Windows показывает мини-плеер в блоке громкости).

**Не приходят уведомления**
- Откройте **Параметры → Конфиденциальность и защита → Доступ к уведомлениям** и разрешите доступ.
- На вкладке **Функции** прочитайте статус под пунктом «Уведомления Windows».
- Функция недоступна, если приложение запущено не из установленного MSIX-пакета (например, через `dotnet run`).

**Не показывается температура** — это ограничение конкретного ПК, см. «Ограничения Windows». Проверить можно командой в PowerShell:

```powershell
Get-CimInstance Win32_PerfFormattedData_Counters_ThermalZoneInformation | Select-Object Name, Temperature
```

Если вывод пустой, Windows не публикует температуру этого компьютера.

**Не срабатывает горячая клавиша** — сочетание занято другим приложением. Назначьте другое в настройках.

**Автозапуск не работает** — проверьте **Параметры → Приложения → Автозагрузка**: Dynamic Edge должен быть включён. Если вы
отключили его там вручную, включить обратно из самого приложения нельзя, сделайте это в параметрах Windows.

### Где лежат файлы и лог

Настройки (`settings.json`) и лог ошибок (`log.txt`) находятся в папке `DynamicEdge` в `%AppData%`. В MSIX-версии Windows
перенаправляет эту папку внутрь пакета. Найти её можно так: вставьте в адресную строку проводника

```
%LocalAppData%\Packages
```

откройте папку, имя которой начинается с `DynamicEdge.App_`, затем `LocalCache\Roaming\DynamicEdge`. Обращаясь за помощью,
приложите содержимое `log.txt`.

## Удаление

1. Откройте **Параметры → Приложения → Установленные приложения**, найдите **Dynamic Edge** и выберите **Удалить**.
2. По желанию удалите сертификат издателя. Выполните в PowerShell от администратора:

   ```powershell
   Get-ChildItem Cert:\LocalMachine\TrustedPeople | Where-Object Subject -eq "CN=DynamicEdge" | Remove-Item
   ```

Настройки при удалении пакета удаляются вместе с ним.

## Сборка из исходников

### Через GitHub Actions (без установки инструментов)

Любой push в ветку `main` запускает workflow `build`: он собирает MSIX и установщик и публикует их как артефакты запуска
(**Actions → последний успешный запуск → Artifacts**). Если создать релиз с тегом вида `v1.1.0`, сборка стартует сама, а
`DynamicEdge-Setup.exe`, `DynamicEdge.msix`, `DynamicEdge.cer` и `install.ps1` прикрепятся к релизу автоматически
(для этого в `build.yml` должно быть указано `permissions: contents: write`). Иначе файлы можно прикрепить к релизу вручную.

### Локально

Нужны Windows 10/11, [.NET 10 SDK](https://dotnet.microsoft.com/download), Windows SDK (из него берутся `makeappx` и
`signtool`) и, для установщика, [Inno Setup 6](https://jrsoftware.org/isinfo.php).

```powershell
# Быстрый запуск без установки (уведомления Windows в таком режиме недоступны)
dotnet run --project src/DynamicEdge

# Сборка подписанного MSIX и установщика → папка artifacts\
powershell -ExecutionPolicy Bypass -File build\package.ps1
```

## Устройство проекта

```
src/DynamicEdge/
  Core/       настройки, тема, автозапуск, вызовы Windows API
  Services/   источники данных: музыка, уведомления, батарея, звук, микрофон,
              буфер обмена, таймер, системная информация, горячие клавиши
  Views/      капсула (IslandWindow), окно настроек, экран приветствия, эквалайзер
build/        манифест MSIX, скрипты упаковки и установки, сценарий Inno Setup
.github/      workflow сборки
```

Капсула работает как конечный автомат `Idle → Hover → Toast → Expanded` с очередью тостов. Окно прозрачное, не
активируется при клике, не отображается в панели задач и Alt+Tab, поддерживает DPI каждого монитора (PerMonitorV2).
Сервисы работают по событиям и опросу с большим интервалом, а тяжёлые операции (выборка CPU и RAM) выполняются только
при развёрнутой панели.

## История версий

### 1.3
- Мониторинг: GPU, диск и скорость сети в панели; те же мини-индикаторы можно вывести в свёрнутую капсулу.
