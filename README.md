# Dynamic Edge для Windows 11

Dynamic Island для Windows: компактная чёрная капсула в верхней части экрана, которая показывает музыку,
уведомления, заряд батареи, громкость, использование микрофона, буфер обмена, таймер и состояние системы.
Приложение написано на C# / WPF (.NET 10) без сторонних NuGet-пакетов и использует реальные API Windows.

## Возможности

| Функция | Что показывает |
|---|---|
| Музыка | Название трека, исполнитель, обложка, прогресс, кнопки Play/Pause, Next, Previous, анимированный эквалайзер. Работает со всеми плеерами, публикующими системную медиасессию (Spotify, Яндекс Музыка, браузеры, Медиаплеер и др.) |
| Уведомления | Иконка приложения-отправителя, заголовок и текст уведомления Windows |
| Батарея | Процент заряда, анимация зарядки, предупреждение о низком заряде |
| Громкость | Анимированный индикатор в реальном времени, состояние «без звука» |
| Микрофон | Индикатор, когда микрофон используется (с названием приложения), уведомление о включении/выключении микрофона |
| Буфер обмена | Тост при копировании, последние 3 записи в развёрнутой панели (клик по записи копирует её обратно) |
| Таймер и секундомер | Обратный отсчёт и секундомер прямо в капсуле, звук и анимация по завершении |
| Система | Загрузка CPU, использование RAM, температура (если доступна) |

Дополнительно: тёмная, светлая и системная тема, настройка формы, анимаций, размера, прозрачности и положения, порядка блоков и пресетов таймера, выбор монитора,
автозапуск, иконка в трее, глобальные горячие клавиши, автоматическое скрытие в полноэкранных играх и презентациях.

## Установка

Требования: Windows 10 (сборка 19041) или Windows 11, 64-разрядная версия.

### Быстрая установка: один файл `DynamicEdge-Setup.exe`

1. Скачайте `DynamicEdge-Setup.exe` (из раздела **Releases** или из артефакта `DynamicEdge-Setup` в **Actions**; готовый файл можно просто переслать другу).
2. Дважды щёлкните по файлу. Если Windows покажет окно «Windows защитила ваш компьютер» (SmartScreen), нажмите **Подробнее → Выполнить в любом случае**: установщик не подписан платным сертификатом, поэтому Windows не знает издателя.
3. Согласитесь на запрос прав администратора и нажмите **Далее → Установить**. Установщик добавит сертификат издателя в доверенные и установит приложение.
4. На последней странице оставьте галочку **Запустить Dynamic Edge** и нажмите **Завершить**.

Установка выполняется для текущего пользователя Windows. Входите в систему и подтверждайте запрос прав той же учётной записью, под которой будете пользоваться приложением. Удаляется приложение как обычно: **Параметры → Приложения → Установленные приложения → Dynamic Edge**.

### Ручная установка из MSIX (альтернатива)

Приложение распространяется как MSIX-пакет. Именно в этом формате работает чтение уведомлений Windows и
корректный автозапуск. Пакет собирается автоматически на GitHub.

### Шаг 1. Получите установочные файлы

1. Откройте вкладку **Actions** этого репозитория.
2. Выберите последний запуск `build` с зелёной галочкой.
3. В самом низу страницы, в разделе **Artifacts**, скачайте `DynamicEdge-MSIX`.
4. Распакуйте скачанный zip-архив в любую папку (например, на рабочий стол).
   Внутри должны быть три файла: `DynamicEdge.msix`, `DynamicEdge.cer`, `install.ps1`.

> Если в репозитории есть раздел **Releases**, те же три файла можно скачать оттуда.

### Шаг 2. Запустите установщик

Все три файла должны лежать в одной папке, и архив должен быть именно **распакован** (не открыт внутри проводника).

**Способ 1 (проще всего).** Нажмите правой кнопкой на `install.ps1` и выберите **Выполнить с помощью PowerShell**.
Согласитесь на запрос прав администратора.

**Способ 2 (если способ 1 не сработал или блокирует политика выполнения скриптов).**
1. Нажмите правой кнопкой на кнопку «Пуск» → **Терминал (Администратор)** или **Windows PowerShell (Администратор)**.
2. Введите команду, подставив путь к файлу. Проще всего ввести её начало и перетащить файл `install.ps1` в окно:

   ```powershell
   powershell -ExecutionPolicy Bypass -File "C:\путь\к\папке\install.ps1"
   ```

> Путь указывайте полностью. Запись вида `Папка\install.ps1` не сработает: PowerShell ищет файл относительно
> текущей папки (обычно `C:\Windows\System32`).

Скрипт делает две вещи: добавляет сертификат издателя в доверенные (`DynamicEdge.cer`, хранилище «Доверенные лица»)
и устанавливает `DynamicEdge.msix`. В конце появится сообщение «Dynamic Edge установлен».

> Почему нужен сертификат: пакет подписан самоподписанным сертификатом (у проекта нет платного сертификата
> издателя). Без добавления сертификата в доверенные Windows откажется устанавливать MSIX.

### Шаг 3. Запустите приложение

1. Найдите **Dynamic Edge** в меню «Пуск» и запустите.
2. При первом запуске откроется окно приветствия. Здесь можно оставить или снять галочку автозапуска. Нажмите **Начать**.
3. Сверху по центру экрана появится капсула, а в системном трее (у часов) — иконка приложения.

### Шаг 4. Разрешите доступ к уведомлениям (по желанию)

Чтобы капсула показывала уведомления Windows, откройте
**Параметры → Конфиденциальность и защита → Доступ к уведомлениям** и разрешите доступ для приложения.
Статус этой функции виден в окне настроек: **Функции → Уведомления Windows**.

## Обновление

1. Закройте приложение: правый клик по иконке в трее → **Выход**.
2. Скачайте свежий артефакт `DynamicEdge-MSIX` из **Actions** (последний успешный запуск) и распакуйте его.
3. Запустите `install.ps1` так же, как при установке. Новая версия установится поверх старой,
   настройки сохранятся.

Каждая сборка получает больший номер версии, поэтому обновление поверх проходит без удаления.

## Использование

### Капсула

| Действие | Результат |
|---|---|
| Ничего не происходит | Маленькая капсула. Если играет музыка, видны обложка и эквалайзер; если идёт таймер — оставшееся время; если используется микрофон — оранжевая точка |
| Навести курсор | Капсула слегка расширяется и показывает дополнительную информацию: трек, время таймера, заряд батареи, часы |
| Клик по капсуле | Раскрывается полная панель |
| Повторный клик | Панель сворачивается |
| Курсор ушёл с панели | Через 5 секунд панель сворачивается сама |
| Событие системы (громкость, зарядка, уведомление, копирование и др.) | Капсула на несколько секунд показывает тост и возвращается в прежнее состояние. Если курсор находится над тостом, он не исчезает |

Капсула не забирает фокус у других окон и не мешает работе: прозрачные области пропускают клики.

### Развёрнутая панель

- **Музыка:** обложка, название, исполнитель, прогресс и кнопки управления плеером.
- **Система:** CPU, RAM (процент и объём), температура. Если датчик недоступен, показывается «н/д».
- **Таймер:** кнопки **1м, 5м, 10м, 25м** запускают обратный отсчёт, кнопка с часами запускает секундомер,
  кнопка с крестиком сбрасывает. Когда таймер закончится, капсула подаст звуковой сигнал и «встряхнётся».
- **Буфер обмена:** последние 3 скопированных текста. Клик по записи копирует её обратно в буфер.
  Содержимое, помеченное менеджерами паролей как скрытое, не показывается.

Блоки, отключённые в настройках, в панели не отображаются.

### Иконка в трее

| Действие | Результат |
|---|---|
| Левый клик | Развернуть / свернуть капсулу |
| Двойной клик | Открыть настройки |
| Правый клик | Меню: развернуть, показать/скрыть капсулу, настройки, выход |

Чтобы полностью закрыть приложение, выберите в меню трея **Выход**.

## Настройки

Откройте настройки двойным кликом по иконке в трее или через её меню. Изменения применяются сразу
и сохраняются автоматически.

**Общие**
- Запуск вместе с Windows.
- Скрытие капсулы в полноэкранных играх и презентациях.
- Автоскрытие капсулы, когда ей нечего показывать.
- Выбор монитора, отступ сверху и смещение по горизонтали.
- Время показа уведомлений, порог предупреждения о низком заряде, длительность таймера по горячей клавише.

**Функции** — включение и выключение каждого блока: музыка, уведомления, батарея, громкость,
микрофон, буфер обмена, таймер, системная информация.

**Внешний вид** — тема (тёмная, светлая, как в Windows), размер капсулы (80–130 %), прозрачность фона.

**Форма и анимации** — подробно в разделе «Кастомизация» ниже.

**Содержимое** — что показывать в свёрнутой капсуле, порядок блоков в панели, свои пресеты таймера.

**Горячие клавиши** — нажмите на поле и введите новое сочетание (обязательно с Ctrl, Alt, Shift или Win).

**О программе** — версия, тип установки, пути к файлам настроек и лога, кнопка открытия папки с данными.

## Кастомизация

Оформление и поведение капсулы можно подстроить под себя. Все изменения применяются сразу. Кнопка
**«Показать в развёрнутом виде (предпросмотр)»** на вкладке «Форма и анимации» разворачивает капсулу и
удерживает её открытой, пока вы подбираете параметры (клик по капсуле снимает удержание).

### Форма и анимации

| Параметр | Что меняет | Диапазон |
|---|---|---|
| Скругление углов | Максимальный радиус: от «таблетки» до почти прямоугольника | 4–40 px |
| Толщина обводки | Тонкая рамка по краю капсулы (0 — без рамки) | 0–3 |
| Сила тени | Глубина тени под капсулой (0 — без тени) | 0–80 % |
| Высота в покое | Размер свёрнутой капсулы | 26–50 px |
| Ширина панели | Ширина развёрнутой панели | 380–560 px |
| Характер раскрытия | **Упругая** (с пружинным «перелётом»), **Мягкая** (плавная без перелёта), **Мгновенная** (размер меняется сразу) | — |
| Сила пружины | Насколько заметен перелёт при упругом раскрытии | 0,1–0,8 |
| Скорость анимаций | Ускоряет или замедляет все переходы | 0,5×–2× |

### Содержимое и раскладка

- **Свёрнутая капсула.** Включайте и отключайте: обложку трека, эквалайзер, название трека и исполнителя,
  таймер, заряд батареи, часы. Если не включено ничего, а в системе ничего не происходит, капсула остаётся пустой
  (или скрывается при включённом автоскрытии).
- **Порядок блоков.** Музыку, систему, таймер и буфер обмена в развёрнутой панели можно расставить в любом порядке
  кнопками «Выше» и «Ниже». Блоки, отключённые на вкладке «Функции», по-прежнему не показываются.
- **Пресеты таймера.** Вместо 1/5/10/25 минут укажите свои значения через запятую (до 5, например `3, 15, 45, 90`).
  Значения от 60 минут, кратные часу, подписываются как «1ч», «2ч».
- **Сброс.** На обеих вкладках есть кнопка возврата к значениям по умолчанию.

## Горячие клавиши

| Сочетание по умолчанию | Действие |
|---|---|
| `Ctrl` + `Alt` + `D` | Развернуть / свернуть капсулу |
| `Ctrl` + `Alt` + `H` | Показать / скрыть капсулу |
| `Ctrl` + `Alt` + `T` | Запустить или остановить таймер (длительность задаётся в настройках, по умолчанию 5 минут) |

Если сочетание занято другим приложением, оно не сработает. Выберите другое в настройках
(информация о неудачной регистрации пишется в лог).

## Ограничения Windows

| Функция | Как реализовано | Особенности |
|---|---|---|
| Музыка | Системные медиасессии (SMTC) | Работает только с плеерами, которые публикуют сессию |
| Уведомления | `UserNotificationListener` | Только в MSIX-версии, нужно разрешение в параметрах Windows |
| Громкость и mute микрофона | Core Audio (`IAudioEndpointVolume`) | Стандартный индикатор громкости Windows остаётся на экране |
| Использование микрофона | Данные Windows о доступе к микрофону | Тот же источник, что у индикатора микрофона в трее |
| Температура | Счётчики PDH «Thermal Zone Information» | Доступна не на всех компьютерах (зависит от BIOS/ACPI). Иначе «н/д» |
| Размытие фона (acrylic) | Не используется | Нестабильно на прозрачных WPF-окнах. Глубину создают полупрозрачность, обводка и тень |

## Если что-то не работает

**Установка не проходит**
- Убедитесь, что файлы `.msix`, `.cer` и `install.ps1` распакованы и лежат в одной папке.
- Запускайте скрипт от имени администратора.
- Если PowerShell пишет, что файл не существует, укажите путь полностью (см. «Шаг 2»).
- Если выполнение скриптов запрещено, используйте способ 2 с параметром `-ExecutionPolicy Bypass`.

**Капсулы не видно**
- Нажмите `Ctrl+Alt+H`: возможно, она скрыта.
- Если на экране полноэкранное приложение или игра, капсула скрыта намеренно (отключается в настройках).
- Проверьте в настройках выбранный монитор и отступ сверху.
- Проверьте, что в трее есть иконка приложения. Если её нет, приложение не запущено, запустите его из меню «Пуск».

**Не показывается музыка**
- Включите воспроизведение в плеере. Если плеер не публикует системную медиасессию, отображение невозможно
  (проверьте: при воспроизведении Windows показывает мини-плеер в блоке громкости).

**Не приходят уведомления**
- Откройте **Параметры → Конфиденциальность и защита → Доступ к уведомлениям** и разрешите доступ.
- Откройте в настройках **Функции** и прочитайте статус под пунктом «Уведомления Windows».
- Функция недоступна, если приложение установлено не из MSIX.

**Не срабатывает горячая клавиша** — сочетание занято другим приложением. Назначьте другое в настройках.

**Автозапуск не работает** — проверьте **Параметры → Приложения → Автозагрузка**: Dynamic Edge должен быть
включён. Если вы отключили его там вручную, включить обратно из самого приложения нельзя, сделайте это в параметрах Windows.

### Где лежат файлы и лог

Настройки (`settings.json`) и лог ошибок (`log.txt`) находятся в папке `DynamicEdge` в `%AppData%`.
В MSIX-версии Windows перенаправляет эту папку внутрь пакета. Её можно найти здесь
(вставьте в адресную строку проводника):

```
%LocalAppData%\Packages
```

Откройте папку, имя которой начинается с `DynamicEdge.App_`, затем `LocalCache\Roaming\DynamicEdge`.
При обращении за помощью приложите содержимое `log.txt`.

## Удаление

1. Откройте **Параметры → Приложения → Установленные приложения**, найдите **Dynamic Edge** и выберите **Удалить**.
2. По желанию удалите сертификат издателя. Выполните в PowerShell от администратора:

   ```powershell
   Get-ChildItem Cert:\LocalMachine\TrustedPeople | Where-Object Subject -eq "CN=DynamicEdge" | Remove-Item
   ```

Настройки при удалении пакета удаляются вместе с ним.

## Сборка из исходников

### Через GitHub Actions (без установки инструментов)

Любой push в ветку `main` запускает workflow `build`, который собирает MSIX и публикует его как артефакт.
Если отправить тег вида `v1.0.0`, пакет дополнительно появится в разделе **Releases**.

### Локально

Нужны Windows 10/11, [.NET 10 SDK](https://dotnet.microsoft.com/download) и Windows SDK
(из него берутся `makeappx` и `signtool`; ставится вместе с Visual Studio или отдельно).

```powershell
# Быстрый запуск без установки (уведомления Windows в таком режиме недоступны)
dotnet run --project src/DynamicEdge

# Сборка подписанного MSIX → папка artifacts\
powershell -ExecutionPolicy Bypass -File build\package.ps1
```

## Устройство проекта

```
src/DynamicEdge/
  Core/       настройки, тема, автозапуск, вызовы Windows API
  Services/   источники данных: музыка, уведомления, батарея, звук, микрофон,
              буфер обмена, таймер, системная информация, горячие клавиши
  Views/      капсула (IslandWindow), окно настроек, экран приветствия, эквалайзер
build/        манифест MSIX, скрипты упаковки и установки
.github/      workflow сборки
```

Капсула работает как конечный автомат `Idle → Hover → Toast → Expanded` с очередью тостов.
Окно прозрачное, не активируется при клике, не отображается в панели задач и Alt+Tab, поддерживает
DPI каждого монитора (PerMonitorV2). Сервисы работают по событиям и опросу с большим интервалом,
а тяжёлые операции (выборка CPU/RAM) выполняются только при развёрнутой панели.
